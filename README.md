NEON BAY is a fictional coastal-city open-world action game in the spirit of GTA 6 — play as Mara Voss through 6 linked story missions: driving, traffic AI, a 1–5 star wanted system, combat, and a full HUD with minimap.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Click to start, WASD to move/drive, mouse to look, P to pause.
